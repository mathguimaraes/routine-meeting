# Security Policy

Routine Meeting is a solo-built macOS app. Audio and transcripts stay on
your Mac by default — nothing is sent anywhere unless you explicitly
enable a cloud AI provider. See the Privacy section in the [README](README.md)
for details.

## Reporting a vulnerability

If you find a security issue, please report it privately rather than
opening a public issue:

- Use GitHub's [private vulnerability reporting](../../security/advisories/new)
  for this repository (Security tab → "Report a vulnerability"), or
- Use the in-app "Send Feedback…" option (menu bar icon → Send Feedback…)
  and note that it's a security report.

Please don't disclose the issue publicly until it's been addressed.

## Scope

This repository distributes compiled release binaries and an update feed
(`appcast.xml`); it does not contain the application's source code.
Reports about the app's behavior, permissions, network activity, or
update mechanism are all in scope.
