Routine Meeting 安静地待在你的菜单栏,在任何应用中检测会议,在你的 Mac 上完成录音和转录,并自动为你生成摘要。

⌘ 下载 macOS 版 在 GitHub 上查看

免费 · Apple Silicon · macOS 13 及以上 · 无需账号

它能做什么

不用你开口,它就把一切都处理好了

不用记着按哪个按钮,不需要针对每个应用单独设置,也不会有"刚才是不是在录音"这种不安时刻。

🎙️

自动检测会议

监听真实对话特有的麦克风+系统音频模式 — 在 Google Meet、Zoom、Teams、Webex、Slack 小组通话、Discord、FaceTime、WhatsApp 通话或转接电话中都能一样运作。

🔒

完全在设备本地转录

WhisperKit 运行在 Apple Silicon 的神经网络引擎上。除非你明确开启云端摘要,否则音频绝不会离开你的 Mac。

🗣️

分得清谁说了什么

麦克风和系统音频分开采集并分离,因此摘要和洞察能准确归属到正确的人。

✅

把对话变成行动

标题、要点摘要、行动事项,还可以选择获得一段诚实的反馈,了解这次对话(无论是一对一、客户电话还是设计评审)进行得如何。

☀️

早晨简报

在你的 Mac 唤醒几分钟后自动生成,包含昨天的回顾和未完成的任务的通知。

🔑

用自己的密钥,或彻底跳过云端

AI 摘要可以使用你自己的免费 Gemini API 密钥,也可以运行完全本地化的模型,不需要密钥,也不产生任何云端调用。

有何不同

没有机器人。没有服务器。一切都在你的 Mac 上。

大多数会议助手,不管是用可见的机器人(Fireflies、Otter)还是"无机器人"式采集(Fellow、Fathom),最终还是会把你的录音和转录发送到它们的服务器处理。

✓
什么都不会离开你的设备 录音和转录完全在设备本地执行。即便和那些标榜"无机器人"的工具相比也是如此,因为"无机器人"只是说没有可见参与者加入通话,并不代表你的数据留在本地。
✓
自动适配所有应用 通过监听真实对话特有的麦克风+系统音频模式来识别会议,而不是以参与者身份加入通话,也不依赖某个特定应用的 API。
✓
用自己的密钥,或彻底跳过云端 使用你自己的 Gemini API 密钥,或运行不需要密钥、不产生云端调用的完全本地模型。
✓
无需账号,无需订阅 完全免费,也不要求你注册任何东西。

开始使用

不到一分钟即可安装

1

下载 — 从 Releases 获取最新的 RoutineMeeting.dmg。

2

打开 DMG,把 Routine Meeting 拖入应用程序文件夹。

3

启动它。一个简短的设置向导会说明每项权限为什么需要,随后弹出系统提示,你可以添加 Gemini 密钥或跳过进入本地模式。

4

就这样。之后它会安静地留在你的菜单栏 — 加入通话,剩下的交给它。

隐私

从设计上就是本地优先

🛡️

音频和转录内容都保留在你的 Mac 上。除非你开启云端 AI 服务商,否则不会向任何地方发送任何内容;即便开启了,发出去的也只有转录文本,绝不会是原始音频。

这款应用每天还会发送一次匿名 ping(一个不含会议内容、姓名或邮箱的随机 ID),以便能以汇总的方式了解使用情况。默认开启,你可以随时在设置 → 隐私中关闭,不会影响其他任何功能。
