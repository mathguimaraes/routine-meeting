회의는 일어난다.
메모는 당신의 일이 아니어야 한다.

Routine Meeting은 메뉴 막대에 자리 잡고, 어떤 앱에서든 회의를 감지하며, Mac에서 모든 것을 녹음·전사하고, 자동으로 요약을 전달합니다.

⌘ macOS용 다운로드 GitHub에서 보기

무료 · Apple Silicon · macOS 13 이상 · 계정 불필요

하는 일

요청 없이도 모든 것을 처리합니다

기억해야 할 버튼도 없고, 앱별 설정도 없고, "이거 녹음되고 있었나?" 하는 불안한 순간도 없습니다.

🎙️

회의를 자동으로 감지

실제 대화의 마이크 + 시스템 오디오 패턴을 감지 — Google Meet, Zoom, Teams, Webex, Slack 허들, Discord, FaceTime, WhatsApp 통화, 전달된 전화까지 동일하게 작동.

🔒

기기에서 완전히 전사

WhisperKit이 Apple Silicon Neural Engine에서 실행됩니다. 클라우드 요약을 명시적으로 활성화하지 않는 한 오디오는 Mac 밖으로 나가지 않습니다.

🗣️

누가 무엇을 말했는지 파악

마이크와 시스템 오디오를 별도로 캡처하고 분리하여, 요약과 인사이트가 올바른 사람에게 귀속됩니다.

✅

대화를 행동으로 전환

제목, 요점 요약, 액션 아이템, 그리고 선택적으로 1:1, 고객 통화, 디자인 리뷰 등 대화가 어떻게 진행됐는지에 대한 솔직한 피드백까지.

☀️

아침 다이제스트

Mac이 깨어난 후 몇 분 뒤 자동으로 생성되는, 어제의 요약과 미완료 작업에 대한 알림.

🔑

직접 키를 쓰거나, 클라우드를 완전히 건너뛰기

AI 요약에는 무료 등급의 Gemini API 키를 사용하거나, 키도 클라우드 호출도 없이 완전히 로컬 모델을 실행할 수 있습니다.

다른 점

봇 없음. 서버 없음. 모든 것이 Mac에서.

대부분의 회의 어시스턴트는 눈에 보이는 봇(Fireflies, Otter)을 쓰든 "봇 없는" 방식(Fellow, Fathom)을 쓰든, 결국 녹음과 전사본을 처리를 위해 자사 서버로 보냅니다.

✓
기기 밖으로 아무것도 나가지 않음 녹음과 전사가 전적으로 기기 내에서 실행됩니다. "봇 없음"을 내세우는 도구와 비교해도 마찬가지입니다. 봇 없음이란 통화에 눈에 보이는 참가자가 들어오지 않는다는 뜻일 뿐, 데이터가 로컬에 머문다는 뜻은 아닙니다.
✓
모든 앱에서 자동으로 작동 참가자로 통화에 들어가거나 특정 앱의 API에 연결하는 대신, 실제 대화의 마이크 + 시스템 오디오 패턴을 감지합니다.
✓
직접 키를 쓰거나, 클라우드를 아예 건너뛰기 본인의 Gemini API 키, 또는 키도 클라우드 호출도 없는 완전한 로컬 모델.
✓
계정도, 구독도 없음 무료이며 어떤 가입도 요구하지 않습니다.

ROUTINE MEETING에 아직 없는 것

  • 회의 간 검색이나 장기적인 지식 베이스 — 현재는 일일 요약으로 제한
  • CRM, Slack, 채용 도구, 다이얼러와의 연동
  • 엔터프라이즈 컴플라이언스 인증(SOC 2, HIPAA, GDPR)
  • Windows 또는 모바일 지원
시작하기

1분 이내에 설치

1

다운로드 — Releases에서 최신 RoutineMeeting.dmg를 받으세요.

2

DMG를 열고 Routine Meeting을 응용 프로그램 폴더로 드래그하세요.

3

앱을 실행하세요. 짧은 설정 가이드가 각 권한이 왜 필요한지 설명한 뒤 시스템 프롬프트를 안내하며, Gemini 키를 추가하거나 온디바이스 모드로 건너뛸 수 있습니다.

4

끝입니다. 이후로는 메뉴 막대에서 조용히 실행됩니다 — 통화에 참여하면 나머지는 알아서 처리됩니다.

설계부터 로컬 우선

🛡️

오디오와 전사본은 Mac에 남습니다. 클라우드 AI 제공업체를 활성화하지 않는 한 어디로도 전송되지 않으며, 활성화하더라도 전사 텍스트만 나갈 뿐 원본 오디오는 절대 나가지 않습니다.

앱은 또한 하루에 한 번 익명 핑을 보냅니다(회의 내용, 이름, 이메일이 없는 무작위 ID). 이를 통해 사용량을 집계 형태로 파악할 수 있습니다. 기본적으로 켜져 있으며, 설정 → 개인정보 보호에서 언제든 끌 수 있고 다른 동작에는 영향이 없습니다.
