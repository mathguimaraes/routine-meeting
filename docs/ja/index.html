会議は起きる。
メモを取るのはあなたの仕事じゃない。

Routine Meetingはメニューバーに常駐し、どんなアプリでも会議を検知して、すべてMac上で録音・文字起こしし、自動で要約を届けます。

⌘ macOS版をダウンロード GitHubで見る

無料 · Apple Silicon · macOS 13以降 · アカウント不要

できること

頼まなくても全部やってくれる

押し忘れるボタンもなく、アプリごとの設定も不要、「今の録音されてた？」という不安な瞬間もない。

🎙️

会議を自動検知

実際の会話特有のマイク＋システム音声のパターンを検知 — Google Meet、Zoom、Teams、Webex、Slackハドル、Discord、FaceTime、WhatsApp通話、転送された電話でも同じように動作。

🔒

すべてデバイス上で文字起こし

WhisperKitがApple SiliconのNeural Engineで動作。クラウド要約を明示的に有効にしない限り、音声はMacの外に出ません。

🗣️

誰が何を言ったかを把握

マイクとシステム音声を別々にキャプチャして分離するため、要約やインサイトが正しい人物に紐づけられます。

✅

会話を実用的な結果に変換

タイトル、箇条書きの要約、アクションアイテム、そして任意で、1on1・クライアント通話・デザインレビューなどそのやり取りがどうだったかの率直なフィードバック。

☀️

朝のダイジェスト

Macが目覚めてから数分後に自動生成される、昨日の要約と未対応タスクの通知。

🔑

自分のキーを使うか、クラウドを完全にスキップ

AI要約には無料枠のGemini APIキーを使うか、キーなし・クラウド呼び出しなしで完全にローカルなモデルを実行できます。

違いのポイント

ボットなし。サーバーなし。すべてMac上で。

多くの会議アシスタントは、目に見えるボット（Fireflies、Otter）を使うにせよ「ボットレス」なキャプチャ（Fellow、Fathom）を使うにせよ、結局は録音と文字起こしを処理のためにサーバーへ送っています。

✓
デバイスの外に何も出ない 録音と文字起こしは完全にデバイス上で実行。「ボットレス」を謳うツールと比べても同様で、ボットレスとは通話に目に見える参加者が加わらないという意味にすぎず、データがローカルに留まるという意味ではありません。
✓
あらゆるアプリで自動的に動作 参加者として通話に加わったり特定アプリのAPIに接続したりするのではなく、実際の会話特有のマイク＋システム音声のパターンを検知。
✓
自分のキーを使うか、クラウドを完全にスキップ 自分のGemini APIキー、またはキーなし・クラウド呼び出しなしの完全ローカルモデル。
✓
アカウント不要、サブスクリプション不要 無料で、登録も一切求めません。

ROUTINE MEETINGにまだないもの

  • 複数会議をまたいだ検索や長期的なナレッジベース — 現状は日次サマリーのみ
  • CRM、Slack、採用管理ツール、ダイヤラーとの連携
  • エンタープライズ向けコンプライアンス認証（SOC 2、HIPAA、GDPR）
  • WindowsやモバイルOSのサポート
はじめかた

1分足らずでインストール

1

ダウンロード — Releasesから最新のRoutineMeeting.dmgを入手。

2

DMGを開いてRoutine Meetingをアプリケーションフォルダにドラッグ。

3

起動する。短いセットアップガイドが各権限について説明し、その後システムのプロンプトが表示され、Geminiキーの追加かオンデバイスモードを選べます。

4

これで完了。あとはメニューバーに静かに常駐 — 通話に参加すれば、残りは自動で処理されます。

プライバシー

設計そのものがローカルファースト

🛡️

音声と文字起こしはMac上に留まります。クラウドAIプロバイダーを有効にしない限り、何も外部に送信されません。有効にした場合でも、外部に出るのは文字起こしのテキストのみで、生の音声が出ることはありません。

このアプリはまた、1日1回匿名のpingを送信します（会議の内容、名前、メールアドレスを含まないランダムなID）。これにより利用状況を集計として把握できます。デフォルトでオンになっていますが、設定 → プライバシーからいつでもオフにでき、それ以外の動作は変わりません。
