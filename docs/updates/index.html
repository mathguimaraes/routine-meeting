Every version

All releases in one list, newest first. Dates are release dates on GitHub.

  • v1.11.0 2026-10-23
    AI-written home page grouped by topic. Task Radar, Insights and the morning recap removed. Cleaner on-device summaries and transcripts.
  • v1.10.1 2026-10-02
    Daily Summary item removed from the menu bar.
  • v1.10.0 2026-10-02
    Task Radar review and manual tasks, calendar Join in the menu bar, live recording timer, no more live transcript preview.
  • v1.9.1 2026-09-11
    Fix for AI summaries failing after Google retired a Gemini fallback model.
  • v1.9 2026-09-10
    Optional calendar integration for meeting titles and attendees. Google Meet tab switching no longer splits a recording. Lower CPU and RAM while recording.
  • v1.8 2026-08-10
    Search across meeting titles, summaries and full transcripts from the sidebar.
  • v1.7 2026-07-30
    Morning digest notification, transcription hang fix (model cache moved out of iCloud-synced folders), macOS 26 icon fix, anonymous daily usage ping (off switch in Settings, Privacy).
  • v1.6 2026-07-23
    Fix for transcription hanging when the model cache sat in an iCloud-synced folder.
  • v1.5 2026-07-22
    App icon fixed on macOS 26 Tahoe. Force Microphone Input recovers after repeated Bluetooth reconnects.
  • v1.4 2026-07-21
    Force Microphone Input backs off automatically if it conflicts with the system input. Two automatic-summary bugs fixed.
  • v1.3 2026-07-20
    App icon rescaled to Apple's standard proportions.
  • v1.2 2026-07-17
    Force Microphone Input (pick a specific mic). App shows in Cmd+Tab while a window is open.
  • v1.1 2026-07-16
    Storage auto-cleanup of old audio, processor log for diagnosing transcription failures, copy-transcript button.
  • v1.0 2026-07-15
    First release under the Routine Meeting name (renamed from MeetingMind). Mic-recovery fix and a first-run setup wizard.
